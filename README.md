# 麻雀れんしゅう帳

麻雀の最低限のルールは知っているけれど、役や待ちがまだ分からない人のための練習アプリです。

- **待ち当てクイズ**:テンパイした手の待ち牌をすべて当てる(Lv1〜3、自動出題)
- **役クイズ**と**役の解説カード**:和了った手についている役を当てる
- **その手、和了れる?**:役なし・片和了・フリテンを見抜く
- **一人打ち練習**:配牌→ツモ→打牌(ヒントの切り替えつき)
- **学習記録**:正答率を記録し、苦手なものを優先して出題

記録はブラウザ(localStorage)に保存します。ログインは不要です。一度開けば、オフライン(機内モードや地下鉄)でも使えます。

## 動かし方

```bash
npm install
npm run dev      # 開発用サーバー(http://localhost:5173)
npm test         # ユニットテスト
npm run build    # 公開用のビルド(dist/)
```

`main` ブランチに push すると、GitHub Actions がテスト・ビルドをして GitHub Pages に公開します。

## 構成

- `src/core/` … 麻雀のロジック(面子分解・和了判定・待ち判定・役判定・フリテン・問題生成)。画面から独立していて、`src/core/__tests__/` でテストしている
- `src/content/` … 解説文・用語集・役の解説カード
- `src/stats/` … 学習記録と苦手優先の重み付け
- `src/components/`, `src/screens/` … 画面
- `scripts/make-icons.mjs` … アプリのアイコン(PNG)を作るスクリプト
